# Archive — pre-product history

The product was developed under the working name SemaDiff and renamed DiffWitness on 29 Sep 2026.
File names and text inside this directory keep the old name as history.

Nothing in this directory is part of the DiffWitness product, is built, or is deployed. It is kept
for transparency about how the product was chosen during HACK47: OFFGRID. Personal notes were
redacted before public release; redactions are marked in place.

| Path | What it is |
|---|---|
| `research/` | Problem and product discovery notes, validation cycles, competitive research, and the decision log that led to DiffWitness (developed under the working name SemaDiff). Status lines inside reflect the time they were written. |
| `afterhours-scaffold/` | A zero-dependency Node scaffold written before a product was selected ("Afterhours" was a placeholder name). Not maintained. |
| `packlock/` | Planning documents for an earlier direction that was abandoned before implementation. |

The product lives in [`packages/diffwitness/`](../packages/diffwitness/); start at the root [`README.md`](../README.md).
