# Getting help

- **Questions and ideas:** start a thread in [GitHub Discussions](https://github.com/CodewithJha/diffwitness/discussions).
- **Bugs:** open an [issue](https://github.com/CodewithJha/diffwitness/issues/new/choose) with the bug report form.
- **Feature requests:** open an issue with the feature request form, or discuss the idea first.
- **Security vulnerabilities:** don't open a public issue; follow [SECURITY.md](SECURITY.md).
- **Contributing code or docs:** see [CONTRIBUTING.md](CONTRIBUTING.md).

Before asking, the [documentation](docs/README.md) and the [CLI troubleshooting table](docs/reference/cli.md#troubleshooting) may already have the answer.

DiffWitness is maintained by one person in their spare time. There is no paid support or guaranteed response time.
