        Causality: not established — a file changing alongside a finding is co-occurrence, never proof of cause.
        
        
        
          Technical explanation
          
        
            
        DiffWitness compares stored digests of each observation from the baseline run and the current run. A mismatch becomes a finding. Git tells us which files differ between the two runs; that list is recorded as the change surface and marked changed alongside.
        
            
        Nothing in that process can prove a file produced a finding, so the engine records the relationship as co-occurrence and leaves causality unasserted. The explainer below is bound by the same rule.
